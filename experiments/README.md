# experiments —— 31 个验证脚本

这里的脚本**不是 demo，是取证**。

项目里每一个"我们就这么做"的决定，背后都有一个脚本跑出来的数字。
`step` 编号和 `docs/` 里的章节一一对应；`docs/11` 和 `docs/13` 里引用了大量 step 号，
想复核任何一条结论，找到对应脚本重跑即可。

## 成本标注

| 标记 | 含义 |
|---|---|
| 🟢 | **0 成本**，不联网，秒级，随时能跑 |
| 🟡 | 要用 API key，但**不生成图**（只调视觉模型解析），一张约 0.002 元 |
| 🔴 | 会**生成图**，0.12~0.30 元 / 张，跑一批之前先确认参数 |
| ⚪ | 需要 `output/` 里**已有产物**（前面某个 step 跑出来的），不能独立跑 |

## 先跑这两个

```bash
python experiments/step25_avoid_cases.py    # 🟢 避让规则 8 条回归
python experiments/step29_routes.py         # 🟢 路线分派 11 条回归
```

`step25` 里的 8 条用例，实质是「她坐到咖啡杯里」那次事故的回放。
改 `s3/scene3d.py` 的任何一行，先跑它。

## 判据为什么是这个

`step25` 的 8 条用例不是随手写的，每一条对应一个**真的出过错**的构图：

| 用例 | 曾经的错 |
|---|---|
| c01 咖啡杯在正中 | 她直接坐进了杯子里（p04 事故） |
| c02 沙发上有一本书 | 书被她的裙摆穿了 |
| c04 花瓶靠左 | 花瓶在左边，她该往右挪 |
| c05 长椅是空的 | **对照组**：不该挪，挪了说明误判 |
| c09 吧台两个杯子 | 两侧都有障碍，只能挪到中间空档 |
| c10 木地板背包 | 背包不是家具，必须躲 |

"该挪的挪了"只是及格，"**不该挪的一点都没动**"才是关键——
c05/c06 两条对照用例就是专门抓"避让过度"的。

## 加一条用例

在 `step25_avoid_cases.py` 的 `CASES` 里加一行，写明场景、期望是否挪动、可接受的像素范围。
跑一遍看是不是 9/9——**先把新用例跑红，再改代码让它变绿**，别反过来。
