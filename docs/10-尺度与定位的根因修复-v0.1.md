# 10 · 尺度与定位的根因修复（v0.1）

> 回应的问题：「图二明显不对，腿过长、角色过大、动作和场景也不匹配」
>
> 结论先说：**"角色过大"和"动作不匹配"不是提示词的问题，是后处理里一个
> 静默失败的 bug——尺度归一从来没有真正执行过。** 前两轮改提示词、改
> `scale_ratio` 参数，全部打在一个没有生效的环节上。

---

## 一、根因链（三层，逐层剥开才看到）

### 第 1 层：`_blue_mask` 在户外照上把蓝天算成了角色

尺度和定位的唯一依据是"角色掩码的包围盒"。原实现用蓝色主导判据
（`b - max(r,g) > 22`），室内白墙场景没问题，户外照有蓝天：

```
16afa9bcc5a6（户外全身照）
  blue_mask bbox = (523, 0, 1280, 1655)     ← 从画面顶边一路到右边框
  贴边？ top=True  right=True
```

`rescale_to_height` 里第一件事就是检查包围盒是否贴边（贴边说明角色被画出
画外，缺失部分补不回来），于是：

```
reason = "touches_border"  → applied = False
```

**关键教训：这个失败是静默的。** 没有异常、没有日志、没有报错，
`scale_info` 里只是多了一个 `applied: False`，而界面上看不出来。
用户看到的症状就是"角色大小完全不受控"。

### 第 2 层：改用差分掩码也会贴边

差分掩码（`change_mask`）会把模型轻微重绘的人物鞋、衣服、地面投影一起算进来：

```
  change_mask bbox = (167, 1035, 1280, 1704)   ← 同样贴边
```

因为模型每次都会把整张图轻微重绘一遍，紧贴画面的"变化区域"总是延伸到边框。

### 第 3 层：正解是两者相交

```
  蓝色主导（蓝天是蓝的，但没变）
  ∩
  差分（牛仔裤变了，但不蓝）
  = 她（既是蓝色主导、又相对原图发生了变化）
```

四张实测底图（户外全身 ×2、室内全身 ×2）交集后包围盒全部不贴边，
且高度与目视一致：

| 底图 | 交集后 bbox | 高度 |
|---|---|---|
| 户外·坐姿 | (523, 1044, 1010, 1655) | 611 |
| 户外·站姿 | (663, 1027, 1057, 1678) | 651 |
| 室内·站姿 A | (695, 909, 1133, 1682) | 773 |
| 室内·站姿 B | (575, 1039, 1113, 1684) | 645 |

实现见 `s3/beautify.py::character_mask()`，耗时约 335 ms。
docstring 里记了完整的排除过程（为什么不用裸差分、为什么不降采样取连通域）。

## 二、尺子换成「人物全身高」

原来的公式是 `目标高度 = 腿框高 × scale_ratio`。问题在于腿框的底边是鞋底、
顶边是**胯部**，而胯部的位置是 VLM 估的——胯部标高一偏，目标高度整体漂。

换成整人身高：`40cm / 175cm ≈ 0.23` 是纯人体测量学比例，不依赖任何估算。
`vlm_locate_pair()` 一次调用同时返回 `person` / `legs` / `light` 三样：

```
16afa9bcc5a6 → person=[328,123,673,986]  legs=[390,573,613,985]  light='left'
```

- `person` 定尺子（高度）和落地线（底边就是鞋底）
- `legs` 定水平位置（放在腿的外侧，不压腿）
- `light` 定阴影方向（见第四节）

`scale_ratio` 的语义随之改为**占人物身高的比例**，标定：

| 动作 | 值 | 含义 |
|---|---|---|
| `leg_hands_behind` | 0.28 | ≈46cm，大号抱枕 |
| `leg_hug_knee` | 0.26 | 坐姿，视觉高度天然更矮 |
| `leg_lean` | 0.28 | 侧靠 |
| `hug_calf` | 0.26 | 蹲抱 |
| `foot_sit` | 0.19 | 坐鞋面，最小 |
| `pull_trouser` | 0.24 | 蹲姿 |

标定过程中试过 0.20，渲出来像一个指甲盖大的小手办，存在感太弱；
0.26~0.28 在整张照片里读起来是"她真在那儿"。

## 三、alpha 与包围盒必须用两套判据

这是修完尺度后暴露出来的第二个坑。包围盒对了、缩放也执行了，
但贴回去的人**是半透明的，下半身还消失了**。

原因：alpha 直接用了 `character_mask`，而它只含"蓝色主导"像素。
她的脸是肤色、围裙和袜子是白色、鞋是深蓝——全被抠掉了。

**要求正好相反：**

| 用途 | 要什么 | 用什么 |
|---|---|---|
| 包围盒 | 最紧，多一点高度就错 | 蓝色 ∩ 差分 |
| alpha | 最全，漏一点就缺一块 | 差分幅度 > 45 |

差分幅度阈值 45 的依据：她是全新画上去的内容，与底图差异常在 60 以上；
模型对背景的重绘是微调，幅度 14~30。实测 25/35/45/60 四档，45 最佳。

### 边界形状：最终用「核心的凸包」

alpha 的边界试了五种，只有凸包同时满足"包住她"和"不漏背景"：

| 方案 | 结果 |
|---|---|
| 差分阈值 14 | 裁切框显形（身后一块发暗矩形），脚下粘着人物球鞋碎片 |
| 差分阈值 45 | 边界顺着她画在地上的投影往外扩，投影被框切断 → 一条带直边的暗带 |
| 行扫描填充 | 把投影包进来，且整行填满 → 矩形色块 |
| 四边泛洪补洞 | 降采样后绕不过她的身体，周围一大片地面被判成"内部" → 一大团灰块 |
| **核心凸包 ∩ 阈值45差分** | 凸包把投影挡在包外，差分保住细腻边缘 ✅ |

最后一步闭运算（核 5）补掉她深色裙摆在阴影里留下的麻点。

实现见 `s3/rescale.py::_alpha_in_box()` / `_convex_hull_mask()`，约 450 ms。

## 四、阴影跟着位置走，方向由 VLM 判

原来 companion 模式的 `auto` 档只有 AO（`azimuth=None`），落地感很弱。
既然已经为定尺子调了一次 VLM，就顺手让它判断主光来向：

```
light ∈ {left, right, top, flat}
  left  → LIGHT_PRESETS["sun_left"]   (户外) / ["left"] (室内)
  right → LIGHT_PRESETS["sun_right"]  / ["right"]
  top   → 顶光，影短
  flat  → 保持 auto（只出 AO，不赌方向）
```

用户显式选了左/右/晴天档时不覆盖——那是他的判断优先。

**同时修掉一个关联 bug**：原代码画阴影用的是 `raw` 的差分框，
但尺度归一执行后她已经**被挪到腿边**了，影子会留在旧位置（"人在左、影在右"）。
现在优先用 `scale_info["placed"]`（缩放后的真实位置）。

效果量化（`8fed040c0cd3`）：

```
改前  shadow=ground_ao    contact_band_delta=3.6
改后  shadow=ground_full  contact_band_delta=17.5
她正下方地面亮度 114 → 52（变暗 54%）
```

## 五、动作描述：腿过长

`leg_hug_knee` 的原描述是"坐在人物脚边的地面上，双腿紧紧蜷起来"，
模型把"蜷起来"理解成"折叠但仍可见大腿+小腿"，于是画出一双长度接近成人的腿。

改成把不可见的部分**明确写成不可见**：

```
坐在人物脚边的地面上，双腿紧紧蜷起来收成一团、小腿完全折在大腿下面看不见，
双手抱着自己的膝盖，下巴搁在膝盖上，仰头看着人物，整体像一个圆圆的小团子
```

真实重跑（`8fed040c0cd3`，Flash）验证：她坐在地上、双腿收成一团，
不再坐在球鞋上，小腿也不拖地。

## 六、定位不再依赖模型的服从度

这是本次改动最实质的一步。

旧链路：`提示词说要放在腿边` → `模型自己决定放哪` → `后处理只负责美化`。
模型把"坐在脚边"理解成"坐在鞋上"，整张图就废了，提示词再改也没用。

新链路：`VLM 给出腿框和脚底线` → `算出她该在哪个像素位置、多高`
→ `掩码把她摘出来、缩放、贴到算好的位置` → `按位置画阴影`。

**模型的自由度只剩下"画成什么样"，位置和大小完全由程序决定。**
所以"动作和场景不匹配"这个问题的性质变了：它不再取决于模型听不听话。

---

## 七、遗留与下一步

1. **坐地型动作的地面参照仍然依赖模型**。她的脚落在算出来的脚底线上，
   但"她认为地面在哪里"仍由模型决定。若模型把她画成悬空姿态，
   后处理只能保证位置对，不能保证姿态对。
2. **横向位置固定放在腿的左侧**（`leg_cx - (leg_w/2 + target_w/2 + 6)`）。
   照片里人物靠画面边缘时会贴边夹紧，可能出现"她被人物的腿挡住一半"。
   更好的做法是判断腿左右两侧哪边有更多可用地面。
3. **alpha 的凸包在凹形姿态下会切掉一点**（手臂与身体分离时）。
   目前靠"凸包切掉超过 45% 就退回原掩码"兜底。
4. **`defringe` 替换率 35%~39%** 偏高，值得单独看一次是否有误伤。
