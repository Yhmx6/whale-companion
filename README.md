# 鲸鱼娘合照

> 上传一张照片，让一个 60cm 高的 Q 版角色出现在里面。位置、动作、表情，由 AI 看着照片决定。

原照片里的人物、光线、家具和背景都保持不变，只在画面中加入角色。

## 两条生成路线

| | auto（默认） | sprite（精确尺寸） |
| --- | --- | --- |
| 做法 | 视觉模型规划构图，程序算出尺寸和落点并生成引导图，再交给生图模型融合 | 角色立绘按真实比例在本地合成 |
| 成本 | 约 0.12 元/张 | 0 |
| 耗时 | 约 16–22 秒 | 约 3–5 秒 |
| 优点 | 光影融合更自然 | 尺寸精确 |
| 代价 | 尺寸有偏差，结果不可复现 | 光影匹配较弱 |

## 细节

- **场景避让**：能识别桌面等物体，避免角色"坐进"杯子里
- **9 种表情**：随机、按场景自动选择或手动指定都可以
- **AI 标识**：导出图右下角自动加入 AI 生成标识
- **角色可替换**：把设定图放进 `assets/characters/`，在 `s3/characters.py` 里注册即可

## 快速开始

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # 填入 ARK_API_KEY
python -m app.server     # http://127.0.0.1:8848
```

或者用 Docker：`docker compose up --build`

打开网页，上传照片，点「生成」。任务异步执行，结果页会附带 `meta` 信息（解析结果、动作理由、表情、尺寸倍率），方便排查。

## 技术栈

Python 3.12+ · 标准库 `ThreadingHTTPServer`（无框架） · 原生 JavaScript（无构建步骤） · 火山引擎方舟（Seedream 生图 + 视觉模型）

## 已知限制

这是一个原型：auto 路线的尺寸系统性偏大、结果不可复现、暗光场景下光影容易脱节，任务状态只保存在内存里。
